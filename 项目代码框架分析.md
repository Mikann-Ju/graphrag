# GraphRAG 项目代码框架和实现逻辑分析

## 项目概述

GraphRAG 是一个基于知识图谱的检索增强生成（RAG）系统，它通过构建结构化的知识图谱来增强大语言模型对私有数据的推理能力。

## 核心架构

### 1. 整体架构设计

```
GraphRAG 系统
├── 索引管道 (Indexing Pipeline) - 构建知识图谱
│   ├── 文档处理
│   ├── 实体关系提取
│   ├── 社区发现
│   └── 嵌入生成
├── 查询引擎 (Query Engine) - 多种搜索模式
│   ├── 本地搜索
│   ├── 全局搜索
│   ├── DRIFT搜索
│   └── 基础搜索
└── 统一搜索应用 (Unified Search App) - Web界面
```

## 索引管道实现逻辑

### 1. 工作流程工厂 (PipelineFactory)

```python
class PipelineFactory:
    workflows: ClassVar[dict[str, WorkflowFunction]] = {}
    pipelines: ClassVar[dict[str, list[str]]] = {}
    
    @classmethod
    def create_pipeline(cls, config: GraphRagConfig, method: IndexingMethod) -> Pipeline:
        # 根据配置和方法创建管道
        workflows = config.workflows or cls.pipelines.get(method, [])
        return Pipeline([(name, cls.workflows[name]) for name in workflows])
```

**标准工作流程**:
1. `load_input_documents` - 加载输入文档
2. `create_base_text_units` - 创建基础文本单元
3. `create_final_documents` - 创建最终文档
4. `extract_graph` - 提取图结构
5. `finalize_graph` - 完成图构建
6. `extract_covariates` - 提取协变量
7. `create_communities` - 创建社区
8. `create_final_text_units` - 创建最终文本单元
9. `create_community_reports` - 创建社区报告

### 2. 搜索模式实现

#### 2.1 本地搜索 (Local Search)
```python
class LocalSearch:
    def query(self, query: str) -> str:
        # 1. 提取查询中的实体
        entities = self.extract_entities(query)
        
        # 2. 构建上下文
        context = self.context_builder.build_context(
            query=query,
            entities=entities,
            text_unit_prop=0.7,  # 70%文本单元
            community_prop=0.3,  # 30%社区信息
        )
        
        # 3. 生成回答
        response = self.model.generate(context + query)
        return response
```

#### 2.2 全局搜索 (Global Search)
```python
class GlobalSearch:
    def query(self, query: str) -> str:
        # 1. Map阶段：为每个社区生成回答
        community_answers = []
        for community in self.communities:
            context = self.build_community_context(community, query)
            answer = self.model.generate(context + query)
            community_answers.append(answer)
        
        # 2. Reduce阶段：合并所有社区回答
        combined_context = self.combine_community_answers(community_answers)
        final_answer = self.model.generate(combined_context + query)
        
        return final_answer
```

#### 2.3 DRIFT搜索 (DRIFT Search)
```python
class DRIFTSearch:
    def query(self, query: str) -> str:
        # 1. 本地搜索获取初始结果
        local_result = self.local_search.query(query)
        
        # 2. 基于社区信息生成后续问题
        follow_up_questions = self.generate_follow_up_questions(
            query, local_result, self.communities
        )
        
        # 3. 对每个后续问题进行搜索
        additional_results = []
        for question in follow_up_questions:
            result = self.local_search.query(question)
            additional_results.append(result)
        
        # 4. 合并所有结果
        combined_result = self.combine_results(local_result, additional_results)
        return combined_result
```

async def run_all_searches(query: str, sv: SessionVariables) -> list[SearchResult]:
    # 并行运行所有搜索模式
    tasks = []
    if sv.include_drift_search.value:
        tasks.append(run_drift_search(query, sv))
    if sv.include_basic_rag.value:
        tasks.append(run_basic_search(query, sv))
    if sv.include_local_search.value:
        tasks.append(run_local_search(query, sv))

    results = await asyncio.gather(*tasks)
    return results

## 缓存机制

### 1. LLM缓存

```python
class PipelineCache:
    def __init__(self, cache_type: CacheType):
        self.cache_type = cache_type
        self.cache = self._create_cache()
    
    def get(self, key: str) -> Any | None:
        return self.cache.get(key)
    
    def set(self, key: str, value: Any):
        self.cache.set(key, value)
    
    def _create_cache(self):
        if self.cache_type == CacheType.MEMORY:
            return MemoryCache()
        elif self.cache_type == CacheType.FILE:
            return FileCache()
        elif self.cache_type == CacheType.COSMOSDB:
            return CosmosDBCache()
```

### 2. 缓存键生成

```python
def generate_cache_key(prompt: str, model_params: dict) -> str:
    # 基于提示和模型参数生成唯一缓存键
    content = f"{prompt}_{json.dumps(model_params, sort_keys=True)}"
    return hashlib.sha256(content.encode()).hexdigest()
```

## 项目特点总结

1. **模块化设计**: 清晰的分层架构，易于扩展和维护
2. **多种搜索模式**: 支持本地、全局、DRIFT和基础搜索
3. **智能缓存**: 内置LLM缓存机制，提高效率
4. **可配置性**: 灵活的配置系统，支持多种模型和参数
5. **Web界面**: 提供用户友好的Web应用
6. **社区发现**: 自动发现和总结知识社区
7. **异步处理**: 支持并发处理，提高性能

这个项目通过将非结构化文本转换为结构化的知识图谱，然后利用多种搜索策略来增强LLM的推理能力，是一个非常有创新性的RAG系统实现。
