# 难负样本挖掘技术指南

## 概述

难负样本挖掘(Hard Negative Mining)是现代信息检索和重排序系统中的核心技术，通过挖掘高质量的难负样本来显著提升模型的判别能力和泛化性能。在企业级应用中，特别是游戏智能分析、搜索引擎、推荐系统等场景，难负样本挖掘直接影响到系统的检索精度和用户体验。

本指南将从理论基础到实际应用，全面介绍难负样本挖掘的各种策略和实现方法。

---

## 1. 难负样本定义

### 1.1 基础概念

**负样本(Negative Sample)**: 在信息检索任务中，对于给定查询q，不相关的文档被称为负样本。

**难负样本(Hard Negative Sample)**: 在所有负样本中，那些**与查询在表面上看起来相关，但实际不相关**的样本，或者**容易被模型错误判断为相关**的负样本。

### 1.2 数学定义

给定查询q和候选文档集合D = {d₁, d₂, ..., dₙ}，设模型预测的相关性分数为f(q, d)：

- **简单负样本**: f(q, d) ≈ 0，模型能够容易区分
- **难负样本**: f(q, d) > τ 但实际标签为0，其中τ为困难阈值

```python
# 难负样本的形式化定义
def is_hard_negative(query, document, model, threshold=0.3):
    """
    判断是否为难负样本
    
    Args:
        query: 查询文本
        document: 候选文档
        model: 训练好的相似度模型
        threshold: 困难阈值
    
    Returns:
        bool: 是否为难负样本
    """
    predicted_score = model.predict_similarity(query, document)
    actual_label = get_ground_truth_label(query, document)
    
    # 难负样本：模型预测分数高但实际不相关
    return predicted_score > threshold and actual_label == 0
```

### 1.3 难负样本的特征

1. **语义迷惑性**: 包含与查询相似的关键词但主题不同
2. **结构相似性**: 文档结构或格式与正样本相似
3. **上下文歧义**: 在特定上下文下容易产生误解
4. **分布边界**: 位于正负样本的决策边界附近

**示例**：
- 查询："Python机器学习教程"
- 简单负样本："Java Web开发指南" (明显不相关)
- 难负样本："Python爬虫教程，涉及数据处理和分析" (包含Python和数据处理，但主题是爬虫)

## 2. 使用背景与重要性

### 2.1 传统训练的局限性

**随机负采样的问题**：
- 大多数随机选择的负样本都是"简单负样本"
- 模型容易在简单样本上过拟合
- 对于边界情况的判别能力不足
- 在实际应用中容易出现误判

### 2.2 难负样本的价值

#### 2.2.1 提升模型判别能力

## 3. 难负样本挖掘策略

### 3.1 静态挖掘策略

#### 3.1.1 Top-K负采样 (Top-K Negative Sampling)

**核心思想**: 使用当前模型对所有负样本进行排序，选择分数最高的K个作为难负样本。

```python
# graphrag/mining/topk_negative_sampler.py

import numpy as np
import torch
from typing import List, Tuple, Dict
from dataclasses import dataclass

@dataclass
class NegativeSample:
    """负样本数据结构"""
    query_id: str
    document_id: str
    content: str
    predicted_score: float
    actual_label: int
    difficulty_score: float

class TopKNegativeSampler:
    """Top-K难负样本挖掘器"""
    
    def __init__(self, 
                 model,
                 k: int = 10,
                 min_score_threshold: float = 0.1,
                 max_score_threshold: float = 0.8):
        self.model = model
        self.k = k
        self.min_threshold = min_score_threshold
        self.max_threshold = max_score_threshold
        
    def mine_hard_negatives(self, 
                          query: str,
                          candidate_docs: List[str],
                          true_negatives: List[int]) -> List[NegativeSample]:
        """挖掘Top-K难负样本"""
        
        # 1. 计算所有候选文档的相似度分数
        scores = self._batch_compute_scores(query, candidate_docs)
        
        # 2. 筛选真实负样本并按分数排序
        negative_samples = []
        for i, (doc, score) in enumerate(zip(candidate_docs, scores)):
            if i in true_negatives and self.min_threshold < score < self.max_threshold:
                difficulty = self._compute_difficulty_score(score)
                negative_samples.append(NegativeSample(
                    query_id=hash(query),
                    document_id=i,
                    content=doc,
                    predicted_score=score,
                    actual_label=0,
                    difficulty_score=difficulty
                ))
        
        # 3. 按困难度排序并返回Top-K
        negative_samples.sort(key=lambda x: x.difficulty_score, reverse=True)
        return negative_samples[:self.k]
    
    def _batch_compute_scores(self, query: str, documents: List[str]) -> List[float]:
        """批量计算相似度分数"""
        with torch.no_grad():
            # 编码查询和文档
            query_embedding = self.model.encode([query])
            doc_embeddings = self.model.encode(documents)
            
            # 计算余弦相似度
            similarities = torch.cosine_similarity(
                query_embedding.unsqueeze(1), 
                doc_embeddings.unsqueeze(0),
                dim=2
            )
            
            return similarities.squeeze().tolist()
    
    def _compute_difficulty_score(self, predicted_score: float) -> float:
        """计算难度分数 - 分数越高越困难"""
        # 使用sigmoid函数将分数映射到难度
        return 1 / (1 + np.exp(-10 * (predicted_score - 0.5)))

# 使用示例
def example_topk_mining():
    """Top-K负采样使用示例"""
    
    # 初始化挖掘器
    sampler = TopKNegativeSampler(model=similarity_model, k=5)
    
    # 挖掘难负样本
    query = "游戏付费转化率分析方法"
    candidates = [
        "游戏收入统计报告",           # 相关但不是分析方法
        "玩家留存率分析工具",         # 分析工具但不是付费转化
        "付费玩家行为特征研究",       # 付费相关但不是转化率
        "免费游戏盈利模式分析",       # 盈利相关但不是转化率分析
        "手游市场竞争分析",          # 简单负样本
    ]
    true_negatives = [0, 1, 2, 3, 4]  # 假设都是负样本
    
    hard_negatives = sampler.mine_hard_negatives(query, candidates, true_negatives)
    
    for sample in hard_negatives:
        print(f"难负样本: {sample.content}")
        print(f"预测分数: {sample.predicted_score:.3f}")
        print(f"难度分数: {sample.difficulty_score:.3f}")
        print("---")
```

#### 3.1.2 边际负采样 (Margin-based Negative Sampling)

**核心思想**: 选择与正样本分数接近但仍为负的样本。

```python
class MarginNegativeSampler:
    """基于边际的难负样本挖掘器"""
    
    def __init__(self, model, margin: float = 0.2):
        self.model = model
        self.margin = margin
    
    def mine_margin_negatives(self, 
                            query: str,
                            positive_docs: List[str],
                            negative_docs: List[str]) -> List[NegativeSample]:
        """基于边际挖掘难负样本"""
        
        # 计算正样本的平均分数
        positive_scores = self._batch_compute_scores(query, positive_docs)
        avg_positive_score = np.mean(positive_scores)
        
        # 计算负样本分数
        negative_scores = self._batch_compute_scores(query, negative_docs)
        
        # 选择分数在 [avg_positive - margin, avg_positive] 范围内的负样本
        hard_negatives = []
        lower_bound = avg_positive_score - self.margin
        upper_bound = avg_positive_score
        
        for i, (doc, score) in enumerate(zip(negative_docs, negative_scores)):
            if lower_bound <= score <= upper_bound:
                hard_negatives.append(NegativeSample(
                    query_id=hash(query),
                    document_id=i,
                    content=doc,
                    predicted_score=score,
                    actual_label=0,
                    difficulty_score=score / avg_positive_score
                ))
        
        return sorted(hard_negatives, key=lambda x: x.predicted_score, reverse=True)
```

### 3.2 动态挖掘策略

#### 3.2.1 SimANS (Similarity-based Adversarial Negative Sampling)

**核心思想**: 通过对抗训练的方式动态生成难负样本，使负样本在嵌入空间中更接近正样本。

```python
# graphrag/mining/simans_sampler.py

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.optim import Adam

class SimANSGenerator(nn.Module):
    """SimANS对抗性负样本生成器"""
    
    def __init__(self, 
                 encoder_model,
                 embedding_dim: int = 768,
                 generator_layers: List[int] = [512, 256, 128]):
        super().__init__()
        self.encoder = encoder_model
        self.embedding_dim = embedding_dim
        
        # 对抗性生成器网络
        layers = []
        input_dim = embedding_dim * 2  # query + positive embedding
        
        for hidden_dim in generator_layers:
            layers.extend([
                nn.Linear(input_dim, hidden_dim),
                nn.ReLU(),
                nn.Dropout(0.1)
            ])
            input_dim = hidden_dim
        
        layers.append(nn.Linear(input_dim, embedding_dim))
        self.generator = nn.Sequential(*layers)
        
        # 判别器网络
        self.discriminator = nn.Sequential(
            nn.Linear(embedding_dim * 2, 256),
            nn.ReLU(),
            nn.Linear(256, 128), 
            nn.ReLU(),
            nn.Linear(128, 1),
            nn.Sigmoid()
        )
    
    def generate_hard_negative(self, 
                             query_embedding: torch.Tensor,
                             positive_embedding: torch.Tensor) -> torch.Tensor:
        """生成难负样本embedding"""
        
        # 拼接query和positive embedding作为生成器输入
        generator_input = torch.cat([query_embedding, positive_embedding], dim=-1)
        
        # 生成对抗性负样本embedding
        negative_embedding = self.generator(generator_input)
        
        # 添加噪声以增加多样性
        noise = torch.randn_like(negative_embedding) * 0.1
        negative_embedding = negative_embedding + noise
        
        # L2标准化
        negative_embedding = F.normalize(negative_embedding, p=2, dim=-1)
        
        return negative_embedding
    
    def adversarial_loss(self, 
                        query_emb: torch.Tensor,
                        pos_emb: torch.Tensor,
                        neg_emb: torch.Tensor) -> torch.Tensor:
        """计算对抗性损失"""
        
        # 生成器损失：希望生成的负样本能够"欺骗"判别器
        gen_neg_emb = self.generate_hard_negative(query_emb, pos_emb)
        
        # 判别器判断生成的负样本是否"困难"
        disc_input = torch.cat([query_emb, gen_neg_emb], dim=-1)
        difficulty_score = self.discriminator(disc_input)
        
        # 生成器希望最大化难度分数
        generator_loss = -torch.log(difficulty_score + 1e-8).mean()
        
        # 判别器损失：区分真实难负样本和简单负样本
        real_hard_input = torch.cat([query_emb, neg_emb], dim=-1) 
        real_difficulty = self.discriminator(real_hard_input)
        
        # 简单负样本 (随机生成)
        simple_neg = torch.randn_like(pos_emb)
        simple_neg = F.normalize(simple_neg, p=2, dim=-1)
        simple_input = torch.cat([query_emb, simple_neg], dim=-1)
        simple_difficulty = self.discriminator(simple_input)
        
        # 判别器希望给难负样本高分，简单负样本低分
        discriminator_loss = (
            -torch.log(real_difficulty + 1e-8).mean() - 
            torch.log(1 - simple_difficulty + 1e-8).mean()
        )
        
        return generator_loss, discriminator_loss

class SimANSTrainer:
    """SimANS训练器"""
    
    def __init__(self, model: SimANSGenerator, lr: float = 1e-4):
        self.model = model
        self.gen_optimizer = Adam(model.generator.parameters(), lr=lr)
        self.disc_optimizer = Adam(model.discriminator.parameters(), lr=lr)
        
    def train_step(self, batch_data: Dict) -> Dict[str, float]:
        """单步训练"""
        
        query_emb = batch_data["query_embeddings"]
        pos_emb = batch_data["positive_embeddings"] 
        neg_emb = batch_data["negative_embeddings"]
        
        # 计算对抗性损失
        gen_loss, disc_loss = self.model.adversarial_loss(query_emb, pos_emb, neg_emb)
        
        # 更新判别器
        self.disc_optimizer.zero_grad()
        disc_loss.backward(retain_graph=True)
        self.disc_optimizer.step()
        
        # 更新生成器
        self.gen_optimizer.zero_grad()
        gen_loss.backward()
        self.gen_optimizer.step()
        
        return {
            "generator_loss": gen_loss.item(),
            "discriminator_loss": disc_loss.item()
        }
    
    def mine_hard_negatives(self, 
                          query_texts: List[str],
                          positive_texts: List[str],
                          num_negatives: int = 5) -> List[torch.Tensor]:
        """使用训练好的模型挖掘难负样本"""
        
        self.model.eval()
        hard_negatives = []
        
        with torch.no_grad():
            for query, positive in zip(query_texts, positive_texts):
                # 编码query和positive
                query_emb = self.model.encoder.encode([query])
                pos_emb = self.model.encoder.encode([positive])
                
                # 生成多个难负样本
                batch_negatives = []
                for _ in range(num_negatives):
                    neg_emb = self.model.generate_hard_negative(
                        torch.tensor(query_emb), 
                        torch.tensor(pos_emb)
                    )
                    batch_negatives.append(neg_emb)
                
                hard_negatives.extend(batch_negatives)
        
        return hard_negatives

# 使用示例

    """SimANS训练示例"""
    
    # 初始化模型和训练器
    encoder = SentenceTransformer('all-MiniLM-L6-v2')
    simans_model = SimANSGenerator(encoder)

    # 训练数据

        "queries": ["游戏付费转化率分析", "玩家留存优化策略"],
        "positives": ["付费转化漏斗分析方法", "提升玩家留存的有效策略"],
        "negatives": ["付费玩家行为统计", "新玩家引导流程优化"]
    }
    
    # 训练循环
    for epoch in range(100):
        # 准备批次数据

                  f"Disc Loss: {losses['discriminator_loss']:.4f}")
    
    # 挖掘难负样本
    hard_negatives = trainer.mine_hard_negatives(
        training_data["queries"], 
        training_data["positives"]
    )
```

#### 3.2.2 SimCSE启发的对比学习

**核心思想**: 利用SimCSE的对比学习框架，通过dropout作为数据增强来挖掘难负样本。

```python
# graphrag/mining/simcse_miner.py

import torch
import torch.nn as nn
from transformers import AutoModel, AutoTokenizer
import torch.nn.functional as F

class SimCSEHardNegativeMiner:
    """基于SimCSE的难负样本挖掘器"""
    
    def __init__(self, 
                 model_name: str = "sentence-transformers/all-MiniLM-L6-v2",
                 temperature: float = 0.05,
                 dropout_rate: float = 0.1):
        
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModel.from_pretrained(model_name)
        self.temperature = temperature
        self.dropout_rate = dropout_rate
        
        # 设置dropout用于数据增强
        self.model.train()
        for module in self.model.modules():
            if isinstance(module, nn.Dropout):
                module.p = dropout_rate
    
    def encode_with_dropout(self, texts: List[str], num_augmentations: int = 2) -> torch.Tensor:
        """使用dropout进行数据增强编码"""
        
        inputs = self.tokenizer(texts, padding=True, truncation=True, 
                               return_tensors="pt", max_length=512)
        
        # 多次前向传播，利用dropout产生不同的表示
        embeddings = []
        for _ in range(num_augmentations):
            with torch.no_grad():
                outputs = self.model(**inputs)
                # Mean pooling
                attention_mask = inputs['attention_mask']
                token_embeddings = outputs.last_hidden_state
                input_mask_expanded = attention_mask.unsqueeze(-1).expand(token_embeddings.size()).float()
                
                pooled = torch.sum(token_embeddings * input_mask_expanded, 1) / torch.clamp(input_mask_expanded.sum(1), min=1e-9)
                embeddings.append(F.normalize(pooled, p=2, dim=1))
        
        return torch.stack(embeddings, dim=1)  # [batch_size, num_augmentations, hidden_dim]
    
    def contrastive_mining(self, 
                          query_texts: List[str],
                          candidate_docs: List[str],
                          true_negatives: List[int],
                          k: int = 10) -> List[NegativeSample]:
        """使用对比学习挖掘难负样本"""
        
        # 1. 编码查询和候选文档
        query_embeddings = self.encode_with_dropout(query_texts, num_augmentations=3)
        doc_embeddings = self.encode_with_dropout(candidate_docs, num_augmentations=1)
        
        hard_negatives = []
        
        for i, query_emb in enumerate(query_embeddings):
            query_text = query_texts[i]
            
            # 2. 计算query的不同dropout版本之间的相似度（作为正样本对）
            query_self_sim = torch.cosine_similarity(
                query_emb[0].unsqueeze(0), 
                query_emb[1:], 
                dim=1
            ).mean()
            
            # 3. 计算query与所有候选文档的相似度
            doc_similarities = []
            for j, doc_emb in enumerate(doc_embeddings):
                if j in true_negatives:
                    sim = torch.cosine_similarity(
                        query_emb[0].unsqueeze(0), 
                        doc_emb[0].unsqueeze(0), 
                        dim=1
                    ).item()
                    doc_similarities.append((j, sim))
            
            # 4. 选择相似度接近query自相似度的负样本作为难负样本
            doc_similarities.sort(key=lambda x: abs(x[1] - query_self_sim.item()))
            
            for doc_idx, sim in doc_similarities[:k]:
                difficulty = self._compute_contrastive_difficulty(sim, query_self_sim.item())
                
                hard_negatives.append(NegativeSample(
                    query_id=f"query_{i}",
                    document_id=f"doc_{doc_idx}",
                    content=candidate_docs[doc_idx],
                    predicted_score=sim,
                    actual_label=0,
                    difficulty_score=difficulty
                ))
        
        return hard_negatives
    
    def _compute_contrastive_difficulty(self, doc_sim: float, query_self_sim: float) -> float:
        """计算对比学习难度分数"""
        # 难度基于与查询自相似度的接近程度
        proximity = 1 - abs(doc_sim - query_self_sim)
        return proximity * doc_sim  # 结合相似度和接近度
    
    def in_batch_negative_mining(self, 
                                batch_queries: List[str],
                                batch_docs: List[str]) -> List[Tuple[int, int, float]]:
        """批次内难负样本挖掘"""
        
        # 编码所有查询和文档
        query_embs = self.encode_with_dropout(batch_queries, num_augmentations=1)[:, 0]  # [batch_size, hidden_dim]
        doc_embs = self.encode_with_dropout(batch_docs, num_augmentations=1)[:, 0]
        
        # 计算相似度矩阵
        sim_matrix = torch.cosine_similarity(
            query_embs.unsqueeze(1), 
            doc_embs.unsqueeze(0), 
            dim=2
        )  # [num_queries, num_docs]
        
        # 对于每个查询，找到最相似的负文档（不是配对的文档）
        hard_negative_pairs = []
        
        for i in range(len(batch_queries)):
            similarities = sim_matrix[i]
            
            # 排除正样本（假设第i个查询对应第i个文档）
            negative_indices = [j for j in range(len(batch_docs)) if j != i]
            negative_sims = similarities[negative_indices]
            
            # 选择相似度最高的负样本
            max_sim_idx = torch.argmax(negative_sims)
            actual_doc_idx = negative_indices[max_sim_idx]
            max_sim_value = negative_sims[max_sim_idx].item()
            
            hard_negative_pairs.append((i, actual_doc_idx, max_sim_value))
        
        return hard_negative_pairs

# 对比学习损失函数
class ContrastiveLoss(nn.Module):
    """对比学习损失函数，集成难负样本挖掘"""
    
    def __init__(self, temperature: float = 0.05):
        super().__init__()
        self.temperature = temperature
    
    def forward(self, 
                query_embeddings: torch.Tensor,
                doc_embeddings: torch.Tensor,
                hard_negative_indices: List[Tuple[int, int]]) -> torch.Tensor:
        """
        计算对比学习损失
        
        Args:
            query_embeddings: [batch_size, hidden_dim]
            doc_embeddings: [batch_size, hidden_dim] 
            hard_negative_indices: [(query_idx, hard_neg_doc_idx), ...]
        """
        batch_size = query_embeddings.size(0)
        
        # 计算所有query-doc对的相似度
        sim_matrix = torch.cosine_similarity(
            query_embeddings.unsqueeze(1),
            doc_embeddings.unsqueeze(0), 
            dim=2
        ) / self.temperature
        
        # 构建标签矩阵
        labels = torch.arange(batch_size).to(query_embeddings.device)
        
        # 计算标准对比学习损失
        loss = F.cross_entropy(sim_matrix, labels)
        
        # 添加难负样本的额外权重
        hard_negative_loss = 0
        for query_idx, hard_neg_idx in hard_negative_indices:
            hard_neg_sim = sim_matrix[query_idx, hard_neg_idx]
            pos_sim = sim_matrix[query_idx, query_idx]
            
            # 增加难负样本的损失权重
            margin_loss = F.relu(hard_neg_sim - pos_sim + 0.2)  # margin = 0.2
            hard_negative_loss += margin_loss
        
        if hard_negative_indices:
            hard_negative_loss /= len(hard_negative_indices)
        
        return loss + 0.5 * hard_negative_loss  # 0.5为难负样本损失权重
```

#### 3.3.1 用户行为反馈挖掘

**核心思想**: 利用用户的实际点击、停留时间等行为数据来识别难负样本。

```python
from typing import List, Dict, Optional
from dataclasses import dataclass
from collections import defaultdict
import numpy as np

@dataclass
class UserFeedback:
    """用户反馈数据"""
    query_id: str
    document_id: str
    click: bool
    dwell_time: float  # 停留时间(秒)
    scroll_depth: float  # 滚动深度(0-1)
    rating: Optional[int]  # 用户评分(1-5)
    timestamp: float

class OnlineFeedbackMiner:
    """基于用户反馈的在线难负样本挖掘器"""
    
    def __init__(self, 
                 click_threshold: float = 0.1,
                 dwell_threshold: float = 5.0,
                 rating_threshold: float = 2.5):
        
        self.click_threshold = click_threshold
        self.dwell_threshold = dwell_threshold  
        self.rating_threshold = rating_threshold
        
        # 存储用户反馈数据
        self.feedback_storage = defaultdict(list)
        
    def collect_feedback(self, feedback: UserFeedback):
        """收集用户反馈"""
        key = f"{feedback.query_id}_{feedback.document_id}"
        self.feedback_storage[key].append(feedback)
    
    def mine_hard_negatives_from_feedback(self, 
                                        model,
                                        min_feedback_count: int = 5) -> List[NegativeSample]:
        """从用户反馈中挖掘难负样本"""
        
        hard_negatives = []
        
        for key, feedbacks in self.feedback_storage.items():
            if len(feedbacks) < min_feedback_count:
                continue
                
            query_id, doc_id = key.split('_')
            
            # 分析用户行为模式
            behavior_analysis = self._analyze_user_behavior(feedbacks)
            
            # 获取模型预测分数
            predicted_score = self._get_model_prediction(model, query_id, doc_id)
            
            # 识别难负样本：模型预测高但用户反馈差
            if (predicted_score > 0.6 and 
                behavior_analysis['is_negative'] and
                behavior_analysis['confidence'] > 0.7):
                
                hard_negatives.append(NegativeSample(
                    query_id=query_id,
                    document_id=doc_id,
                    content=self._get_document_content(doc_id),
                    predicted_score=predicted_score,
                    actual_label=0,
                    difficulty_score=behavior_analysis['difficulty']
                ))
        
        return hard_negatives
    
    def _analyze_user_behavior(self, feedbacks: List[UserFeedback]) -> Dict:
        """分析用户行为模式"""
        
        # 统计各种行为指标
        click_rate = sum(f.click for f in feedbacks) / len(feedbacks)
        avg_dwell_time = np.mean([f.dwell_time for f in feedbacks])
        avg_scroll_depth = np.mean([f.scroll_depth for f in feedbacks])
        
        ratings = [f.rating for f in feedbacks if f.rating is not None]
        avg_rating = np.mean(ratings) if ratings else 3.0
        
        # 判断是否为负样本
        is_negative = (
            click_rate < self.click_threshold or
            avg_dwell_time < self.dwell_threshold or
            avg_rating < self.rating_threshold
        )
        
        # 计算置信度和难度
        confidence = self._compute_behavior_confidence(feedbacks)
        difficulty = self._compute_behavior_difficulty({
            'click_rate': click_rate,
            'dwell_time': avg_dwell_time,
            'scroll_depth': avg_scroll_depth,
            'rating': avg_rating
        })
        
        return {
            'is_negative': is_negative,
            'confidence': confidence,
            'difficulty': difficulty,
            'click_rate': click_rate,
            'avg_dwell_time': avg_dwell_time,
            'avg_rating': avg_rating
        }
    
    def _compute_behavior_confidence(self, feedbacks: List[UserFeedback]) -> float:
        """计算行为分析的置信度"""
        
        # 基于样本数量和行为一致性
        sample_count = len(feedbacks)
        count_confidence = min(sample_count / 20.0, 1.0)  # 20个样本达到满置信度
        
        # 行为一致性（方差小表示一致性高）
        dwell_times = [f.dwell_time for f in feedbacks]
        dwell_variance = np.var(dwell_times)
        consistency_confidence = 1 / (1 + dwell_variance / 10.0)
        
        return (count_confidence + consistency_confidence) / 2
    
    def _compute_behavior_difficulty(self, behavior_stats: Dict) -> float:
        """计算行为难度分数"""
        
        # 难度基于用户行为的"欺骗性"
        # 点击率适中但停留时间短 = 高难度
        click_deception = behavior_stats['click_rate'] * (1 - min(behavior_stats['dwell_time'] / 30.0, 1.0))
        
        # 滚动深度高但评分低 = 高难度  
        scroll_deception = behavior_stats['scroll_depth'] * (1 - behavior_stats['rating'] / 5.0)
        
        return (click_deception + scroll_deception) / 2

# 实时学习系统
class OnlineHardNegativeLearner:
    """在线难负样本学习系统"""
    
    def __init__(self, base_model, update_frequency: int = 1000):
        self.base_model = base_model
        self.update_frequency = update_frequency
        self.feedback_buffer = []
        self.hard_negative_buffer = []
        self.update_counter = 0
        
    def process_user_interaction(self, 
                               query: str,
                               documents: List[str],
                               user_feedback: UserFeedback):
        """处理用户交互，实时更新难负样本"""
        
        self.feedback_buffer.append(user_feedback)
        self.update_counter += 1
        
        # 定期更新模型
        if self.update_counter % self.update_frequency == 0:
            self._update_model_with_hard_negatives()
    
    def _update_model_with_hard_negatives(self):
        """使用难负样本更新模型"""
        
        # 从反馈中挖掘新的难负样本
        miner = OnlineFeedbackMiner()
        for feedback in self.feedback_buffer:
            miner.collect_feedback(feedback)
        
        new_hard_negatives = miner.mine_hard_negatives_from_feedback(self.base_model)
        self.hard_negative_buffer.extend(new_hard_negatives)
        
        # 保持缓冲区大小
        if len(self.hard_negative_buffer) > 5000:
            # 保留最新和最困难的样本
            self.hard_negative_buffer.sort(key=lambda x: x.difficulty_score, reverse=True)
            self.hard_negative_buffer = self.hard_negative_buffer[:3000]
        
        # 使用难负样本进行增量学习
        self._incremental_training(new_hard_negatives)
        
        # 清空反馈缓冲区
        self.feedback_buffer = []
    
    def _incremental_training(self, hard_negatives: List[NegativeSample]):
        """增量训练模型"""
        
        if not hard_negatives:
            return
        
        # 准备训练数据
        training_pairs = []
        for sample in hard_negatives:
            # 添加难负样本对
            training_pairs.append({
                'query': self._get_query_text(sample.query_id),
                'positive': self._get_random_positive(sample.query_id),
                'negative': sample.content,
                'weight': sample.difficulty_score  # 根据难度加权
            })
        
        # 执行增量训练（这里简化为概念代码）
        self.base_model.incremental_fit(training_pairs)
        
        print(f"使用 {len(hard_negatives)} 个难负样本完成增量训练")
```

#### 3.3.2 主动学习挖掘

**核心思想**: 主动选择最有价值的样本进行标注，重点关注模型不确定的样本。

```python
# graphrag/mining/active_learning_miner.py

import numpy as np
from sklearn.cluster import KMeans
from typing import List, Tuple, Dict
import torch

class ActiveLearningMiner:
    """主动学习难负样本挖掘器"""
    
    def __init__(self, 
                 model,
                 uncertainty_threshold: float = 0.3,
                 diversity_weight: float = 0.3):
        
        self.model = model
        self.uncertainty_threshold = uncertainty_threshold
        self.diversity_weight = diversity_weight
        
    def mine_uncertain_samples(self, 
                             query_texts: List[str],
                             candidate_docs: List[str],
                             budget: int = 50) -> List[Tuple[str, str, float]]:
        """挖掘不确定的样本用于主动标注"""
        
        # 1. 计算所有query-doc对的预测分数
        uncertainty_scores = []
        
        for i, query in enumerate(query_texts):
            for j, doc in enumerate(candidate_docs):
                # 获取模型预测及其不确定性
                prediction, uncertainty = self._predict_with_uncertainty(query, doc)
                
                uncertainty_scores.append({
                    'query_idx': i,
                    'doc_idx': j, 
                    'query': query,
                    'document': doc,
                    'prediction': prediction,
                    'uncertainty': uncertainty,
                    'score': prediction
                })
        
        # 2. 选择高不确定性的样本
        uncertain_samples = [
            sample for sample in uncertainty_scores 
            if sample['uncertainty'] > self.uncertainty_threshold
        ]
        
        # 3. 在不确定样本中增加多样性选择
        selected_samples = self._diversified_selection(uncertain_samples, budget)
        
        return [(s['query'], s['document'], s['uncertainty']) for s in selected_samples]
    
    def _predict_with_uncertainty(self, query: str, document: str) -> Tuple[float, float]:
        """预测相关性并估计不确定性"""
        
        # Monte Carlo Dropout估计不确定性
        predictions = []
        self.model.train()  # 启用dropout
        
        with torch.no_grad():
            for _ in range(10):  # 10次前向传播
                pred = self.model.predict_similarity(query, document)
                predictions.append(pred)
        
        mean_pred = np.mean(predictions)
        uncertainty = np.std(predictions)  # 标准差作为不确定性度量
        
        return mean_pred, uncertainty
    
    def _diversified_selection(self, 
                             samples: List[Dict], 
                             budget: int) -> List[Dict]:
        """多样性选择避免选择过于相似的样本"""
        
        if len(samples) <= budget:
            return samples
        
        # 获取样本的embedding表示
        embeddings = []
        for sample in samples:
            # 简化：使用query和document的拼接作为表示
            combined_text = sample['query'] + " " + sample['document']
            emb = self.model.encode([combined_text])[0]
            embeddings.append(emb)
        
        embeddings = np.array(embeddings)
        
        # 使用聚类实现多样性选择
        n_clusters = min(budget, len(samples))
        kmeans = KMeans(n_clusters=n_clusters, random_state=42)
        cluster_labels = kmeans.fit_predict(embeddings)
        
        # 从每个聚类中选择不确定性最高的样本
        selected_samples = []
        for cluster_id in range(n_clusters):
            cluster_samples = [
                samples[i] for i in range(len(samples)) 
                if cluster_labels[i] == cluster_id
            ]
            
            if cluster_samples:
                # 选择该聚类中不确定性最高的样本
                best_sample = max(cluster_samples, key=lambda x: x['uncertainty'])
                selected_samples.append(best_sample)
        
        return selected_samples
    
    def update_with_annotations(self, 
                              annotated_samples: List[Tuple[str, str, int]],
                              learning_rate: float = 1e-5):
        """使用标注数据更新模型"""
        
        # 准备训练数据
        training_data = []
        hard_negatives = []
        
        for query, document, label in annotated_samples:
            training_data.append((query, document, label))
            
            # 识别难负样本（模型预测高但实际为负）
            pred_score = self.model.predict_similarity(query, document)
            if pred_score > 0.5 and label == 0:
                hard_negatives.append(NegativeSample(
                    query_id=hash(query),
                    document_id=hash(document),
                    content=document,
                    predicted_score=pred_score,
                    actual_label=label,
                    difficulty_score=pred_score  # 预测分数作为难度
                ))
        
        # 使用标注数据进行微调
        self._fine_tune_model(training_data, learning_rate)
        
        return hard_negatives
    
    def _fine_tune_model(self, training_data: List[Tuple], learning_rate: float):
        """微调模型"""
        # 这里是模型微调的概念代码
        optimizer = torch.optim.Adam(self.model.parameters(), lr=learning_rate)
        
        for epoch in range(5):  # 少量epoch避免过拟合
            total_loss = 0
            
            for query, document, label in training_data:
                # 计算预测和损失
                pred = self.model.predict_similarity(query, document)
                loss = torch.nn.BCELoss()(torch.tensor([pred]), torch.tensor([float(label)]))
                
                # 反向传播
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
                
                total_loss += loss.item()
            
            print(f"Fine-tuning Epoch {epoch+1}, Average Loss: {total_loss/len(training_data):.4f}")

class ActiveLearningLoop:
    """主动学习循环管理器"""
    
    def __init__(self, 
                 model,
                 annotation_budget: int = 100,
                 iterations: int = 5):
        
        self.model = model
        self.miner = ActiveLearningMiner(model)
        self.annotation_budget = annotation_budget
        self.iterations = iterations
        self.total_annotated = 0
        
    def run_active_learning_loop(self, 
                                query_pool: List[str],
                                document_pool: List[str],
                                oracle_function) -> List[NegativeSample]:
        """运行主动学习循环"""
        
        all_hard_negatives = []
        budget_per_iteration = self.annotation_budget // self.iterations
        
        for iteration in range(self.iterations):
            print(f"\n=== 主动学习迭代 {iteration + 1} ===")
            
            # 1. 挖掘不确定样本
            uncertain_samples = self.miner.mine_uncertain_samples(
                query_pool, document_pool, budget_per_iteration
            )
            
            print(f"选择了 {len(uncertain_samples)} 个不确定样本进行标注")
            
            # 2. 获取人工标注（这里使用oracle函数模拟）
            annotations = []
            for query, doc, uncertainty in uncertain_samples:
                label = oracle_function(query, doc)  # 0或1
                annotations.append((query, doc, label))
                self.total_annotated += 1
            
            # 3. 使用标注更新模型并挖掘难负样本
            iteration_hard_negatives = self.miner.update_with_annotations(annotations)
            all_hard_negatives.extend(iteration_hard_negatives)
            
            print(f"发现 {len(iteration_hard_negatives)} 个难负样本")
            
            # 4. 评估当前模型性能
            self._evaluate_current_performance(query_pool[:10], document_pool[:50])
        
        print(f"\n主动学习完成！总计标注 {self.total_annotated} 个样本，发现 {len(all_hard_negatives)} 个难负样本")
        return all_hard_negatives
    
    def _evaluate_current_performance(self, eval_queries: List[str], eval_docs: List[str]):
        """评估当前模型性能"""
        
        # 简化的评估逻辑
        total_uncertainty = 0
        count = 0
        
        for query in eval_queries:
            for doc in eval_docs[:5]:  # 每个查询评估5个文档
                _, uncertainty = self.miner._predict_with_uncertainty(query, doc)
                total_uncertainty += uncertainty
                count += 1
        
        avg_uncertainty = total_uncertainty / count if count > 0 else 0
        print(f"当前模型平均不确定性: {avg_uncertainty:.4f}")
```

```python
# graphrag/reranking/hard_negative_reranker.py

from typing import List, Dict, Tuple
import torch
import torch.nn as nn
from transformers import AutoModel, AutoTokenizer

class HardNegativeAwareReranker(nn.Module):
    """集成难负样本挖掘的重排序模型"""
    
    def __init__(self, 
                 base_model_name: str = "cross-encoder/ms-marco-MiniLM-L-12-v2",
                 hard_negative_weight: float = 2.0):
        super().__init__()
        
        self.tokenizer = AutoTokenizer.from_pretrained(base_model_name)
        self.encoder = AutoModel.from_pretrained(base_model_name)
        self.classifier = nn.Linear(self.encoder.config.hidden_size, 1)
        self.hard_negative_weight = hard_negative_weight
        
        # 集成的难负样本挖掘器
        self.negative_miners = {
            'topk': TopKNegativeSampler(self, k=10),
            'simans': None,  # 需要预训练
            'simcse': SimCSEHardNegativeMiner(),
            'online': OnlineFeedbackMiner()
        }
        
    def forward(self, input_ids, attention_mask, token_type_ids=None):
        """前向传播"""
        outputs = self.encoder(
            input_ids=input_ids,
            attention_mask=attention_mask,
            token_type_ids=token_type_ids
        )
        
        # 使用[CLS]token的表示
        cls_embedding = outputs.last_hidden_state[:, 0]
        logits = self.classifier(cls_embedding)
        
        return torch.sigmoid(logits.squeeze())
    
    def rerank_with_hard_negatives(self, 
                                 query: str,
                                 documents: List[str],
                                 top_k: int = 10,
                                 mine_negatives: bool = True) -> List[Dict]:
        """使用难负样本增强的重排序"""
        
        # 1. 基础重排序
        base_scores = self._compute_base_scores(query, documents)
        
        # 2. 挖掘难负样本（如果启用）
        hard_negatives = []
        if mine_negatives:
            # 使用多种策略挖掘难负样本
            for miner_name, miner in self.negative_miners.items():
                if miner is not None:
                    try:
                        negatives = miner.mine_hard_negatives(
                            query, documents, list(range(len(documents)))
                        )
                        hard_negatives.extend(negatives)
                    except Exception as e:
                        print(f"挖掘器 {miner_name} 执行失败: {e}")
        
        # 3. 调整分数（降低难负样本的分数）
        adjusted_scores = self._adjust_scores_with_hard_negatives(
            base_scores, documents, hard_negatives
        )
        
        # 4. 排序并返回top-k
        scored_docs = [
            {
                'document': doc,
                'original_score': base_score,
                'adjusted_score': adj_score,
                'is_hard_negative': any(hn.content == doc for hn in hard_negatives)
            }
            for doc, base_score, adj_score in zip(documents, base_scores, adjusted_scores)
        ]
        
        scored_docs.sort(key=lambda x: x['adjusted_score'], reverse=True)
        return scored_docs[:top_k]
    
    def _compute_base_scores(self, query: str, documents: List[str]) -> List[float]:
        """计算基础相关性分数"""
        scores = []
        
        for doc in documents:
            # 编码query-document对
            inputs = self.tokenizer(
                query, doc,
                padding=True,
                truncation=True,
                max_length=512,
                return_tensors="pt"
            )
            
            # 获取相关性分数
            with torch.no_grad():
                score = self.forward(**inputs).item()
                scores.append(score)
        
        return scores
    
    def _adjust_scores_with_hard_negatives(self, 
                                         base_scores: List[float],
                                         documents: List[str],
                                         hard_negatives: List[NegativeSample]) -> List[float]:
        """使用难负样本调整分数"""
        
        adjusted_scores = base_scores.copy()
        
        # 创建难负样本内容到索引的映射
        hard_negative_contents = {hn.content: hn for hn in hard_negatives}
        
        for i, (doc, base_score) in enumerate(zip(documents, base_scores)):
            if doc in hard_negative_contents:
                hard_negative = hard_negative_contents[doc]
                
                # 根据难负样本的难度调整分数
                penalty = hard_negative.difficulty_score * self.hard_negative_weight
                adjusted_scores[i] = max(0, base_score - penalty)
        
        return adjusted_scores
    
    def train_with_hard_negatives(self, 
                                training_data: List[Tuple[str, str, int]],
                                hard_negative_ratio: float = 0.3,
                                epochs: int = 3,
                                learning_rate: float = 2e-5):
        """使用难负样本训练重排序模型"""
        
        optimizer = torch.optim.AdamW(self.parameters(), lr=learning_rate)
        criterion = nn.BCELoss()
        
        for epoch in range(epochs):
            total_loss = 0
            num_batches = 0
            
            # 在每个epoch中挖掘新的难负样本
            for query, document, label in training_data:
                
                # 正常训练样本
                inputs = self.tokenizer(
                    query, document,
                    padding=True, truncation=True, max_length=512,
                    return_tensors="pt"
                )
                
                pred = self.forward(**inputs)
                loss = criterion(pred, torch.tensor([float(label)]))
                
                # 如果是正样本，添加难负样本
                if label == 1 and torch.rand(1).item() < hard_negative_ratio:
                    # 挖掘该查询的难负样本
                    candidates = self._get_candidate_negatives(query)
                    hard_negatives = self.negative_miners['topk'].mine_hard_negatives(
                        query, candidates, list(range(len(candidates)))
                    )
                    
                    # 添加难负样本损失
                    for hard_neg in hard_negatives[:2]:  # 最多2个难负样本
                        neg_inputs = self.tokenizer(
                            query, hard_neg.content,
                            padding=True, truncation=True, max_length=512,
                            return_tensors="pt"
                        )
                        
                        neg_pred = self.forward(**neg_inputs)
                        neg_loss = criterion(neg_pred, torch.tensor([0.0]))
                        
                        # 难负样本使用更高的权重
                        loss += self.hard_negative_weight * neg_loss
                
                # 反向传播
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
                
                total_loss += loss.item()
                num_batches += 1
            
            avg_loss = total_loss / num_batches if num_batches > 0 else 0
            print(f"Epoch {epoch+1}/{epochs}, Average Loss: {avg_loss:.4f}")

class HardNegativeEvaluator:
    """难负样本效果评估器"""
    
    def __init__(self):
        self.metrics = ['precision', 'recall', 'f1', 'ndcg', 'mrr']
    
    def evaluate_hard_negative_impact(self, 
                                    model_without_hn,
                                    model_with_hn,
                                    test_queries: List[str],
                                    test_documents: List[List[str]],
                                    ground_truth: List[List[int]]) -> Dict:
        """评估难负样本对模型性能的影响"""
        
        results = {
            'without_hard_negatives': {},
            'with_hard_negatives': {},
            'improvement': {}
        }
        
        # 评估无难负样本模型
        results['without_hard_negatives'] = self._evaluate_model(
            model_without_hn, test_queries, test_documents, ground_truth
        )
        
        # 评估有难负样本模型  
        results['with_hard_negatives'] = self._evaluate_model(
            model_with_hn, test_queries, test_documents, ground_truth
        )
        
        # 计算改进幅度
        for metric in self.metrics:
            without_score = results['without_hard_negatives'][metric]
            with_score = results['with_hard_negatives'][metric]
            improvement = (with_score - without_score) / without_score * 100
            results['improvement'][metric] = improvement
        
        return results
    
    def _evaluate_model(self, 
                       model,
                       queries: List[str],
                       documents: List[List[str]],
                       ground_truth: List[List[int]]) -> Dict:
        """评估单个模型"""
        
        all_scores = {metric: [] for metric in self.metrics}
        
        for query, docs, truth in zip(queries, documents, ground_truth):
            # 获取模型预测分数
            scores = model._compute_base_scores(query, docs)
            
            # 计算各种指标
            precision = self._calculate_precision(scores, truth, k=10)
            recall = self._calculate_recall(scores, truth, k=10)
            f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
            ndcg = self._calculate_ndcg(scores, truth, k=10)
            mrr = self._calculate_mrr(scores, truth)
            
            all_scores['precision'].append(precision)
            all_scores['recall'].append(recall)
            all_scores['f1'].append(f1)
            all_scores['ndcg'].append(ndcg)
            all_scores['mrr'].append(mrr)
        
        # 返回平均分数
        return {metric: np.mean(scores) for metric, scores in all_scores.items()}
    
    def generate_evaluation_report(self, results: Dict) -> str:
        """生成评估报告"""
        
        report = "=== 难负样本效果评估报告 ===\n\n"
        
        report += "1. 基线模型性能 (无难负样本):\n"
        for metric, score in results['without_hard_negatives'].items():
            report += f"   {metric.upper()}: {score:.4f}\n"
        
        report += "\n2. 改进模型性能 (有难负样本):\n"
        for metric, score in results['with_hard_negatives'].items():
            report += f"   {metric.upper()}: {score:.4f}\n"
        
        report += "\n3. 性能提升幅度:\n"
        for metric, improvement in results['improvement'].items():
            report += f"   {metric.upper()}: {improvement:+.2f}%\n"
        
        # 总结
        avg_improvement = np.mean(list(results['improvement'].values()))
        report += f"\n总体平均提升: {avg_improvement:+.2f}%\n"
        
        if avg_improvement > 5:

        elif avg_improvement > 0:
            report += "⚡ 难负样本挖掘带来了适度的性能提升。"
        else:
            report += "❌ 难负样本挖掘未能提升模型性能，需要调整策略。"
        
        return report
```

```python
            await self._store_feedback(feedback)
            return {"status": "success"}
        
        @self.app.get("/stats/mining")
        async def get_mining_stats():
            return await self._get_mining_statistics()
    
    async def _mine_with_strategy(self, 
                                strategy: str, 
                                request: QueryRequest) -> MiningResponse:
        """使用指定策略挖掘难负样本"""
        
        start_time = time.time()
        
        # 检查缓存
        cache_key = f"mining:{strategy}:{hash(request.query + str(request.candidates))}"
        cached_result = self.redis_client.get(cache_key)
        
        if cached_result:
            result = json.loads(cached_result)
            return MiningResponse(
                hard_negatives=result['hard_negatives'],
                mining_time=result['mining_time'],
                strategy_used=strategy + "_cached"
            )
        
        # 执行挖掘
        loop = asyncio.get_event_loop()
        hard_negatives = await loop.run_in_executor(
            self.thread_pool,
            self._sync_mine,
            strategy, request.query, request.candidates
        )
        
        mining_time = time.time() - start_time
        
        # 缓存结果
        result = {
            'hard_negatives': [hn.__dict__ for hn in hard_negatives],
            'mining_time': mining_time
        }
        self.redis_client.setex(cache_key, 3600, json.dumps(result))  # 1小时缓存
        
        return MiningResponse(
            hard_negatives=result['hard_negatives'],
            mining_time=mining_time,
            strategy_used=strategy
        )
    
    def _select_best_strategy(self, query: str, candidates: List[str]) -> str:
        """自动选择最佳挖掘策略"""
        
        # 基于查询和候选文档特征选择策略
        query_length = len(query.split())
        num_candidates = len(candidates)
        avg_doc_length = np.mean([len(doc.split()) for doc in candidates])
        
        if num_candidates < 20:
            return 'topk'  # 候选少时使用Top-K
        elif query_length > 10 and avg_doc_length > 50:
            return 'simcse'  # 复杂查询使用SimCSE
        else:
            return 'topk'  # 默认策略
    
    async def _store_feedback(self, feedback: dict):
        """存储用户反馈"""
        feedback_key = f"feedback:{feedback['query_id']}:{feedback['doc_id']}"
        self.redis_client.lpush(f"feedback_queue", json.dumps(feedback))
        
        # 触发在线学习更新
        if self.redis_client.llen("feedback_queue") > 100:
            await self._trigger_online_learning()
    
    async def _trigger_online_learning(self):
        """触发在线学习更新"""
        # 获取反馈数据
        feedbacks = []
        for _ in range(100):
            feedback_data = self.redis_client.rpop("feedback_queue")
            if feedback_data:
                feedbacks.append(json.loads(feedback_data))
        
        # 异步更新在线学习模型
        loop = asyncio.get_event_loop()
        await loop.run_in_executor(
            self.thread_pool,
            self._update_online_model,
            feedbacks
        )
```

## 5. 总结与最佳实践

### 5.1 策略选择指南

| 场景 | 推荐策略 | 优点 | 适用条件 |
|------|----------|------|----------|
| **冷启动阶段** | Top-K + Margin | 简单有效，无需预训练 | 有基础模型，数据量中等 |
| **数据丰富** | SimANS + SimCSE | 效果最佳，能生成高质量样本 | 大量训练数据，充足计算资源 |
| **在线系统** | Online Feedback | 能持续改进，贴近真实场景 | 有用户交互数据，支持实时更新 |
| **标注预算有限** | Active Learning | 标注效率高，性价比好 | 有专家标注，预算有限 |

### 5.2 实施建议

#### 5.2.1 渐进式部署

1. **第一阶段**: 使用Top-K负采样建立基线
2. **第二阶段**: 集成SimCSE对比学习提升效果  
3. **第三阶段**: 部署在线反馈挖掘实现持续优化
4. **第四阶段**: 引入主动学习降低标注成本

**问题**: 难负样本挖掘计算开销大  
**解决方案**:
- 使用缓存减少重复计算
- 批量处理提高效率
- 异步挖掘避免阻塞

#### 5.3.3 过拟合风险

**问题**: 模型在难负样本上过拟合
**解决方案**:
- 控制难负样本比例
- 使用正则化技术
- 定期验证泛化性能
